# Frosty Client (Fabric)

A lightweight Fabric utility client for Minecraft 1.21.11.

## Features

- Toggleable HUD overlay with module states
- Toggleable auto-sprint
- Toggleable fullbright (night vision effect)

Default keybinds:
- `Right Shift`: Toggle HUD
- `R`: Toggle auto-sprint
- `F`: Toggle fullbright

> You can rebind all keys from Minecraft's Controls menu.

## Platform support

Frosty Client is implemented with Fabric + Java and is intended to run on:
- macOS
- Linux
- Windows 10+

Requirements:
- Java 21+
- Fabric Loader 0.18.2+
- Minecraft 1.21.11

## Development

Build locally:

```bash
./gradlew build
```
